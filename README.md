# Smart AI Bot 🤖

An AI-powered chatbot built using React.js that allows users to interact with AI, upload images, and generate images.

## 🚀 Live Demo

[View Smart AI Bot](https://smartbotbyaksa.netlify.app/)

## ✨ Features

- **AI Chat:** Get text-based responses using the Gemini API.
- **Image Upload:** Upload images and interact with AI using image input.
- **AI Image Generation:** Generate images using Cloudflare Workers AI.
- **Interactive UI:** Simple and user-friendly interface built with React.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Gemini API
- Cloudflare Workers AI
- Vite

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/aksagori/smart-ai-bot.git
   ```

2. Navigate to the project folder:

   ```bash
   cd smart-ai-bot
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the root folder and add your Gemini API key:

   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```
